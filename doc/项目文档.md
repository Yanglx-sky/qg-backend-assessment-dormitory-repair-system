# 宿舍报修系统项目文档

## 1. 项目概述

### 1.1 项目背景
随着高校宿舍管理的日益复杂，传统的报修流程存在效率低下、信息不透明等问题。为了提高报修处理效率，增强学生、维修人员和管理员之间的沟通，开发一套宿舍报修系统显得尤为必要。

### 1.2 项目目标
- 实现学生在线提交报修申请
- 实现维修人员接取和处理订单
- 实现管理员对系统的全面管理
- 提供良好的用户体验和界面设计

### 1.3 项目范围
本系统主要面向高校宿舍管理，包括学生、维修人员和管理员三个角色，实现报修流程的全生命周期管理。

## 2. 技术栈

### 2.1 前端技术
- **框架**：Vue 3
- **状态管理**：Pinia
- **路由**：Vue Router
- **HTTP 客户端**：Axios
- **构建工具**：Vite
- **CSS 预处理器**：原生 CSS

### 2.2 后端技术
- **框架**：Spring Boot
- **数据库**：MySQL
- **ORM**：MyBatis-Plus
- **认证**：JWT
- **文件存储**：阿里云 OSS

### 2.3 其他技术
- **版本控制**：Git
- **项目管理**：Maven

## 3. 系统架构

### 3.1 前端架构
- **单页应用**：基于 Vue 3 的单页应用
- **组件化开发**：将页面拆分为多个可复用组件
- **路由管理**：使用 Vue Router 实现页面导航
- **状态管理**：使用 Pinia 管理全局状态
- **API 调用**：统一使用 axiosInstance 进行 API 请求，包含请求/响应拦截器

### 3.2 后端架构
- **分层架构**：
  - Controller 层：处理 HTTP 请求
  - Service 层：实现业务逻辑
  - Mapper 层：数据访问
- **全局异常处理**：使用 @RestControllerAdvice 实现统一异常处理
- **JWT 认证**：实现无状态认证

## 4. 功能模块

### 4.1 用户管理
- **登录**：支持不同角色用户登录
- **注册**：学生注册功能
- **退出**：用户退出登录
- **Token 刷新**：自动刷新过期的访问令牌

### 4.2 学生模块
- **首页**：显示欢迎信息和功能导航
- **宿舍管理**：查看和绑定宿舍信息
- **订单管理**：查看历史报修订单
- **提交报修**：提交新的报修申请，支持图片上传

### 4.3 维修人员模块
- **首页**：显示欢迎信息和功能导航
- **接取订单**：查看和接取待处理的报修订单
- **我的订单**：查看已接取的订单，更新订单状态

### 4.4 管理员模块
- **首页**：显示系统概览
- **订单管理**：查看和管理所有报修订单
- **宿舍管理**：管理宿舍信息
- **学生管理**：管理学生信息
- **维修人员管理**：管理维修人员信息

## 5. 核心流程

### 5.1 报修流程
1. 学生登录系统
2. 提交报修申请（填写报修信息，上传图片）
3. 系统生成报修订单
4. 维修人员查看待处理订单
5. 维修人员接取订单
6. 维修人员处理订单
7. 维修人员完成订单
8. 学生确认订单完成

### 5.2 认证流程
1. 用户输入账号密码登录
2. 系统验证用户信息
3. 生成 JWT 令牌（accessToken 和 refreshToken）
4. 前端存储令牌
5. 每次请求携带 accessToken
6. 当 accessToken 过期时，使用 refreshToken 刷新
7. 当 refreshToken 也过期时，跳转到登录页

## 6. 数据库设计

### 6.1 主要表结构
- **users**：用户表（id, account, password, userName, roleId, createTime）
- **dormitories**：宿舍表（id, dormNumber, buildingNumber, userId, createTime）
- **repairOrders**：报修订单表（id, userId, repairmanId, title, description, status, createTime, updateTime）
- **orderImages**：订单图片表（id, orderId, imageUrl, createTime）
- **roles**：角色表（id, roleName）

### 6.2 关系图
```
users --1:N--> repairOrders
users --1:N--> dormitories
repairOrders --1:N--> orderImages
users --N:1--> roles
```

## 7. 关键技术点

### 7.1 图片上传
- 使用阿里云 OSS 存储图片
- 前端使用 FormData 上传图片
- 后端使用 OSS SDK 处理上传

### 7.2 JWT 认证
- 实现无状态认证
- 支持 Token 刷新
- 前端自动处理 Token 过期

### 7.3 全局异常处理
- 后端使用 @RestControllerAdvice 实现统一异常处理
- 前端使用 axios 拦截器处理错误响应

### 7.4 响应式设计
- 适配不同屏幕尺寸
- 移动端友好的界面

## 8. 部署方案

### 8.1 前端部署
- 构建生产版本：`npm run build`
- 将 dist 目录部署到 Web 服务器

### 8.2 后端部署
- 打包成 jar 包：`mvn package`
- 部署到 Java 应用服务器
- 配置数据库连接和 OSS 配置

### 8.3 环境要求
- **前端**：Node.js 14+，npm 6+
- **后端**：JDK 1.8+，Maven 3.6+
- **数据库**：MySQL 5.7+
- **存储**：阿里云 OSS 服务
